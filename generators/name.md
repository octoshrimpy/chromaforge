# Generate Place Name

Names for regions, towns, rivers, ruins, and villages, drawn from Katharra's Global Name Bank (grouped by the land they suit) and coloured by which people did the naming.

## steps

| die    | label   | depends |
| ------ | ------- | ------- |
| `1d10` | terrain |         |
| `1d10` | name    | terrain |
| `1d6`  | namer   |         |

### terrain

| roll | result                          |
| ---- | ------------------------------- |
| 1    | warm moist coast                |
| 2    | rocky / sandy coast             |
| 3    | dry desert / wind-cut stone     |
| 4    | cold / high desert              |
| 5    | cool pine coast                 |
| 6    | old inland / megalithic country |
| 7    | river valley / farmland         |
| 8    | marsh / reedland                |
| 9    | mountain / alpine               |
| 10   | wet forest / jungle             |

### namer

_who's name became the common one — sets the flavour and any older/alternate names._

| roll | result                                                                                    |
| ---- | ----------------------------------------------------------------------------------------- |
| 1, 2 | Old Sorelleth — druidic, megalithic; a name inherited from standing stones and boundaries |
| 3, 4 | Maritime explorers — the living Romance-sounding tongue of sailors, mapmakers, and ports  |
| 5    | Inland common — a plain, descriptive settler name (like Pineview)                         |
| 6    | contested — two peoples, two names; whichever mapmaker won                                |
