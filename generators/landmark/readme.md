# Generate Landmark

Any color tile may grab a landmark from a nearby color — check the clockwise color order in [colors & houses](/compendium/colors_houses/readme.md).

## steps

| die    | label    | depends  |
| ------ | -------- | -------- |
| `1d10` | category |          |
| `1d6`  | landmark | category |

_optional: instead of rolling `1d10` for category, roll `1d6` where 1-3 keeps natural/man-made from the previous landmark (previous/same/next color per the clockwise order) and 4-6 does the same for man-made._
