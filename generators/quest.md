# Generate Quest

A hook: what they're asked to do, the catch, and what's on offer.

## steps

| die    | label  | depends |
| ------ | ------ | ------- |
| `1d10` | goal   |         |
| `1d6`  | twist  |         |
| `1d6`  | reward |         |

### goal

| roll | result                                                                     |
| ---- | -------------------------------------------------------------------------- |
| 1    | recover a stolen {{pick: heirloom \| relic \| ledger \| body}}             |
| 2    | escort someone who doesn't want to go                                      |
| 3    | put down a beast that's been taking livestock                              |
| 4    | carry word to a place people don't come back from                          |
| 5    | find out why the {{pick: crops \| wells \| children \| dead}} have changed |
| 6    | hold a place against something coming                                      |
| 7    | fetch a thing from where it very much belongs                              |
| 8    | make peace between two parties who both lie                                |
| 9    | open what was sealed for a reason                                          |
| 10   | find the last person who took this same job                                |

### twist

| roll | result                                               |
| ---- | ---------------------------------------------------- |
| 1    | the one who hired them is lying about why            |
| 2    | there's a clock — someone else is already moving     |
| 3    | the "monster" is a victim; the victim is the monster |
| 4    | finishing it breaks something that was holding       |
| 5    | a party member is quietly the wrong choice           |
| 6    | it's a test, and someone is watching how they do it  |

### reward

| roll | result                                      |
| ---- | ------------------------------------------- |
| 1    | coin, less than promised                    |
| 2    | coin, and a debt owed                       |
| 3    | a thing worth more than money to one person |
| 4    | knowledge nobody else has                   |
| 5    | a favor from someone who matters            |
| 6    | nothing clean — only a way out              |
