# Generate Group

A band encountered together — what they are, how many, and how they react.

## steps

| die   | label       | depends |
| ----- | ----------- | ------- |
| `1d6` | makeup      |         |
| `1d6` | size        |         |
| `1d6` | disposition |         |

### makeup

| roll | result                               |
| ---- | ------------------------------------ |
| 1, 2 | a pack of beasts — {{gen: monster}}  |
| 3, 4 | an armed band — {{gen: monster}}     |
| 5    | travelers or refugees — {{gen: npc}} |
| 6    | a cult or order — {{gen: npc}}       |

### size

| roll | result        |
| ---- | ------------- |
| 1, 2 | a pair        |
| 3, 4 | a few (3-5)   |
| 5    | a mob (6-9)   |
| 6    | a horde (10+) |

### disposition

| roll | result                         |
| ---- | ------------------------------ |
| 1    | hostile — strike first         |
| 2    | wary — flee if they can        |
| 3    | indifferent — ignore the party |
| 4    | curious — approach to look     |
| 5    | friendly — offer aid or trade  |
| 6    | desperate — need help, badly   |
